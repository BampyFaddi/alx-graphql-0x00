# Episodes Query for alx-graphql-0x00

This directory contains GraphQL queries and output JSON files for episodes with IDs 1–4.

## Files
- episode-id-1.graphql
- episode-id-1-output.json
- episode-id-2.graphql
- episode-id-2-output.json
- episode-id-3.graphql
- episode-id-3-output.json
- episode-id-4.graphql
- episode-id-4-output.json

Each `.graphql` file contains a query to fetch details for a specific episode:
- `id`
- `name`
- `air_date`
- `episode`

Data fetched from: **https://rickandmortyapi.graphcdn.app/**
